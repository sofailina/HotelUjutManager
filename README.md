## Описание проекта

WPF-приложение «HotelUjutManager» для автоматизации работы администратора гостиницы.  
Система позволяет управлять бронированиями, проживающими гостями, сотрудниками, а также контролировать уборку номеров.

## Структура проекта

### Основные окна приложения:
1. **MainWindow.xaml** – Главное окно приложения (точка входа).
2. **BookingWindow.xaml** – Окно управления бронированиями (создание, изменение, отмена).
3. **GuestsWindow.xaml** – Окно со списком и карточками гостей.
4. **EmployeesWindow.xaml** – Окно управления сотрудниками отеля.
5. **CleaningWindow.xaml** – Окно контроля уборки номеров.

### Классы и модели (папка `Models`):
- Модели данных (гость, номер, бронирование, сотрудник, график уборки и т.д.)

### Файлы конфигурации и проекта:
- `App.config` – конфигурация приложения (строка подключения к БД и др.)
- `App.xaml` / `App.xaml.cs` – точка входа, ресурсы приложения
- `HotelUjutManager.csproj` – файл проекта
- `HotelUjutManager.sln` – файл решения Visual Studio
- `.gitattributes`, `.gitignore` – настройки Git

## Технологии

- **Язык:** C#  
- **Платформа:** .NET Framework, WPF  
- **База данных:** (предположительно) SQL Server / SQLite (согласно `App.config`)  
- **Архитектура:** клиент-серверная или локальная с БД

## Основные функции

1. **Управление бронированиями** – создание, изменение, отмена, просмотр занятости номеров.
2. **Работа с гостями** – добавление, редактирование, поиск, история проживаний.
3. **Управление персоналом** – список сотрудников, назначение на уборку, смены.
4. **Контроль уборки** – отметка о выполнении, график, ответственные горничные.
5. **Единая точка входа** – главное окно с навигацией по всем разделам.

## База данных (предполагаемая структура)

Проект, вероятно, использует реляционную БД со следующими основными таблицами:
- `Guests` – гости
- `Rooms` – номера
- `Bookings` – бронирования
- `Employees` – сотрудники
- `CleaningSchedule` – график уборки
- `RoomStatuses` – статусы номеров

## Запуск проекта

1. Открыть `HotelUjutManager.sln` в Visual Studio (2019/2022).
2. Восстановить пакеты NuGet (при необходимости).
3. Настроить строку подключения в `App.config` под вашу СУБД.
4. Собрать и запустить проект (F5).
